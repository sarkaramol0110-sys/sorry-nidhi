# Sorry Nidhi ❤️

A simple, romantic/friendly apology website made with plain HTML, CSS and JavaScript.

## GitHub Pages — easiest upload

1. Create a new repository on GitHub, for example `sorry-nidhi`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. GitHub will give you a free `github.io` website address.

No server or paid hosting is required.

## Customize

Open `index.html` in any text editor and change the apology text, signature, or button messages.

You can add photos later by creating an `images` folder and using:
`<img src="images/your-photo.jpg" alt="Our memory">`
